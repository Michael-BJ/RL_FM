================================================================================
GAZEBO SETTINGS & WORLD POLES CONFIGURATION
ROS2 Launch: expert_planning.launch.py + sitl.launch.py
================================================================================

COMMAND YANG DIJALANKAN:
================================================================================
ros2 launch fm_planner expert_planning.launch.py \
  pcd_path:=/home/michael/poles.pcd \
  target_samples:=500

CATATAN PENTING:
- Command ini TIDAK meluncurkan Gazebo sendiri
- Ini adalah node-node planning yang bekerja dengan simulasi Gazebo yang sudah berjalan
- Gazebo harus sudah berjalan terlebih dahulu dengan command berikut


================================================================================

================================================================================

================================================================================
SETTINGAN EXPERT PLANNING UNTUK WORLD "POLES"
================================================================================

Occupancy Band untuk World Poles:
- occ_min_z = 1.0 m  (Min Z proyeksi 2D)
- occ_max_z = 3.0 m  (Max Z proyeksi 2D)
- Obstacle pendek = 3.36m
- Drone altitude = 1.5m

Catatan: Untuk world "bricks", gunakan occ_min_z=0.5

================================================================================

target_samples          : 500 (Anda gunakan, default=5000)
goal_x                  : 15.0 m (Koordinat X goal)
target_alt              : 1.5 m (Altitude drone target)
replan_period           : 1.0 s (Periode replanning)
cmd_hz                  : 100 Hz (Frekuensi publish ke MAVROS)
v_max                   : 1.0 m/s (Kecepatan maksimal drone)

occ_min_z               : 1.0 m (Min Z proyeksi 2D - POLES SPECIFIC)
occ_max_z               : 3.0 m (Max Z proyeksi 2D)
use_ekf_stable          : true (Tunggu EKF Z konvergen sebelum takeoff)
data_save_dir           : auto (Generate folder dengan timestamp)

================================================================================
FAST-DDS/FASTRTPS CLEANUP
================================================================================

Saat start, sitl.launch.py otomatis:
1. Berhentikan semua proses Gazebo/PX4/ROS lama (SIGTERM)
2. Paksa-kill proses yang masih hidup (SIGKILL)
3. Bersihkan socket dan port yang terkunci
4. Hapus shared memory FastDDS yang stale
5. Restart ROS2 daemon
6. Hapus PX4 unix socket
7. Hapus file state PX4 (parameters.bson, dataman)

Ini dilakukan untuk menghindari MAVROS crash pada saat restart.


================================================================================
TROUBLESHOOTING
================================================================================

Jika expert_planner crash atau tidak merespons:
1. Pastikan Gazebo sudah running:
   ros2 launch fm_planner sitl.launch.py vehicle:=x500_depth world:=poles

2. Tunggu sampai "Gazebo GUI" muncul (12 detik)

3. Verify node yang running:
   ros2 node list
   ros2 topic list

4. Check occ_min_z/occ_max_z sesuai world (untuk poles: 1.0/3.0)

5. Jika masih error, restart dengan sitl.launch.py yang akan bersihkan semua

Data save location:
- Default: ~/training_data/run_YYYYMMDD_HHMMSS/
- Jika ingin custom: data_save_dir:=/path/to/folder


================================================================================
FULL LAUNCH COMMAND SEQUENCE
================================================================================

Terminal 1 (Gazebo & PX4):
ros2 launch fm_planner sitl.launch.py vehicle:=x500_depth world:=poles

Terminal 2 (Expert Planning - tunggu 15 detik, pastikan Gazebo GUI muncul):
ros2 launch fm_planner expert_planning.launch.py \
  pcd_path:=/home/michael/poles.pcd \
  target_samples:=500

Terminal 3+ (Monitoring - opsional):
# Monitor nodes
ros2 node list

# Monitor topics
ros2 topic list

# Monitor expert planner output
ros2 topic echo /expert_planner/path
